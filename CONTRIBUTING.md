# Contributing

Thanks for helping. This project eats its own cooking: every change ships with proof.

1. Open an issue first for anything larger than a typo, so we agree on the problem.
2. Keep skills short. A skill earns a line only if an agent would do worse without it.
3. Hooks stay dependency-free (Node 18+ standard library only) and must be silent when they allow.
4. Add or update a test in `tests/` for every hook change, then run `npm test`.
5. In the PR description, paste the command you ran and its result (the `evidence-before-done` format).
